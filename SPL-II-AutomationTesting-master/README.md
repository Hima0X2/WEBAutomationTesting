# SPL-II Automation Testing 🔍

This section of the repository is dedicated to **exploratory testing** activities conducted as part of the Software Project Lab II (SPL-II) academic project. It focuses on evaluating system behavior without predefined test cases, aiming to discover bugs through dynamic investigation and experience-based techniques.

## 🧪 What is Exploratory Testing?

Exploratory testing is an approach where test design, execution, and learning happen simultaneously. Instead of following scripted test cases, testers explore the system to uncover unexpected behavior, usability issues, and hidden bugs.

## 🎯 Objectives

- Identify critical bugs through real-time exploration  
- Understand system behavior and workflows  
- Evaluate user experience and design inconsistencies  
- Complement scripted automation with manual insight  

## 🔧 Tools Used

- Java  
- Selenium WebDriver  
- TestNG (optional for structured logs)  
- Maven  
- Manual observation and note-taking for test design  

## 📝 Activities Performed

- Explored the UI/UX flow manually to identify usability gaps  
- Performed scenario-based testing to simulate real user actions
