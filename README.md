# WEBAutomationTesting 
A collection of Selenium-based automated test scripts for multiple web applications. This project includes test cases for various real-world platforms, created to demonstrate end-to-end automation capabilities.  
  
## 🔧 Technologies Used  
- Java
- Selenium WebDriver
- TestNG
- Maven

## ▶️ How to Run  
1. Clone the repository:  
`git clone https://github.com/Hima0X2/WEBAutomationTesting.git`  
`cd WEBAutomationTesting`  
2. Open the project in IntelliJ IDEA or Eclipse  
3. Install dependencies using Maven:  
`mvn clean install`  
4. Run the tests:  
`mvn test`

## 🧪 Test Coverage  
This project contains automated test cases for:  
- 🛒 E-commerce Platforms: Islamic Shop Dhaka, Othoba.com, Wafilife  
- 👩‍💼 HR Software: OrangeHRM  
- 🎓 Academic Project: SPL-II Automation Testing
